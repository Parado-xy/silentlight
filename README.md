# Silent Light

**Security shouldn't be a luxury.**

Coming-soon website for Silent Light, a discreet personal safety system being designed for moments when calling for help isn't possible.

## Local preview

This is a zero-build static site. Serve the repository root with any static HTTP server, or open `index.html` for a basic preview.

## Deploy on Render

The repository includes `render.yaml` for a Render Static Site. Create a new Blueprint in Render and select this repository. Render will publish the repository root and automatically redeploy changes from the default branch.

## Brand assets

- `logo.svg` — transparent white Silent Light mark for dark backgrounds
- `favicon.svg` — browser favicon variant
